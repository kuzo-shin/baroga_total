# 바로가 ERP — GAS 배포 가이드

## ★ 엠즈 재고 DB(7번째, 2026-11-24 신규) 만들기
엠즈 e플랫폼에서 읽은 현재고·유통기한·수불부·가맹점 발주 자료를 보관하는 DB입니다. 재고·반품 자료가 들어 있어 공개 저장소가 아니라 이 시트에만 둡니다.
1. 구글 드라이브에서 **새 스프레드시트** 만들기 (이름 예: `엠즈 재고 DB`)
2. 시트 → **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `7_ms_stock.gs` 전체 붙여넣기 → 저장
3. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성** → `ACCESS_CODE` = 다른 DB와 **같은 접속 코드**
4. **배포 → 새 배포** → 유형 **웹 앱** → 실행: **나**, 액세스: **모든 사용자** → 배포 → 웹 앱 주소(…/exec) 복사
5. 사이트 **엠즈 재고** → **[DB 연결]** → 주소 붙여넣기 → 저장 후 불러오기
6. 엠즈 e플랫폼에 로그인한 뒤 Claude에게 "엠즈 재고 갱신해줘" 요청 → 자료를 읽어 DB에 저장

## ★ 원재료 단가 비교 DB(6번째, 2026-11-23 신규) 만들기
매입 단가·업체 연락처가 들어 있어 GitHub(공개)가 아닌 이 DB에만 저장합니다.
1. 구글 드라이브에서 **새 구글 시트** 생성 (예: `바로가_원재료단가비교_DB`)
2. 시트 → **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `6_price_compare.gs` 전체 붙여넣기 → 저장
3. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성** → `ACCESS_CODE` = 다른 DB와 **같은 접속 코드**
4. **배포 → 새 배포** → 유형 **웹 앱** → 실행: **나**, 액세스: **모든 사용자** → 배포 → 웹 앱 주소(…/exec) 복사
5. 사이트 **원재료 → 5. 원재료 단가 비교** → **[DB 연결]** → 주소 붙여넣기 → 저장 후 불러오기
6. **[자료 가져오기]** → Claude가 만든 단가 비교 HTML(`baroga_price_compare.html`) 또는 JSON 선택 → 개수 확인 → **DB에 저장**
   - 저장하면 시트에 `PRICE_COMPARE_DB`(원본), `품목별_비교`, `업체별_연락처`(사람이 보는 표) 탭이 생깁니다.

## ★ 생산일지 DB(5번째, 2026-11-21 신규) 만들기
1. 구글 드라이브에서 **새 구글 시트** 생성 (예: `바로가_생산일지_DB`)
2. 시트 → **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `5_production.gs` 전체 붙여넣기 → 저장
3. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성** → `ACCESS_CODE` = 다른 4개 DB와 **같은 접속 코드**
4. **배포 → 새 배포** → 유형 **웹 앱** → 실행: **나**, 액세스: **모든 사용자** → 배포 → 웹 앱 주소(…/exec) 복사
5. 사이트 **생산일지** 탭 → **[DB 연결]** → 주소 붙여넣기 → 저장 후 불러오기 (기기마다 한 번)
   - 주소를 넣기 전에는 입력한 내용이 그 기기(브라우저)에만 저장됩니다. 연결하면 처음 한 번 DB로 올라갑니다.

## ★ 2단계(접속 코드 인증, GAS v2.1) 배포 순서
1. **접속 코드 정하기**: 팀이 함께 쓸 코드 1개 (10자 이상, 영문+숫자 섞어서 권장). 이 코드는 코드·GitHub 어디에도 적지 않습니다.
2. **4개 Apps Script에 코드 등록** (시트마다 반복, 4개 모두 같은 코드)
   - Apps Script 왼쪽 **⚙ 프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
   - 속성: `ACCESS_CODE` / 값: 정한 접속 코드 → **스크립트 속성 저장**
3. **GAS 코드 교체**: 이 폴더의 `.gs` 4개(v2.1)를 각각 통째로 붙여넣기 → 저장 → **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**
   - "새 배포"를 누르지 마세요 (주소가 바뀜)
4. **사이트 반영**: GitHub PR 병합 (3번과 4번 사이에는 사이트가 잠시 "불러오기 실패"로 보이니 연달아 진행)
5. **각 기기에서 한 번 입력**: 사이트 접속 → 뜨는 창에 접속 코드 입력 → 4개 탭 "DB 연동됨" 확인
   - 상단 **[접속 코드]** 버튼으로 다시 입력하거나 이 기기에서 지울 수 있습니다.
6. **예전 배포 보관처리 (필수)**: 각 Apps Script → 배포 관리 → 예전 배포(옛 주소)를 선택 → **보관처리**
   - 예전 배포는 인증 없는 옛 코드로 계속 돌아가며, 옛 주소는 GitHub 기록에 남아 있습니다. 보관처리해야 접근이 막힙니다.

### 접속 코드를 바꾸려면
4개 Apps Script의 스크립트 속성 `ACCESS_CODE` 값을 모두 새 코드로 바꾸면 즉시 적용됩니다 (재배포 불필요). 각 기기에는 새 코드 입력 창이 뜹니다.

# 1단계(데이터 손실 방지) 배포 가이드

이 폴더의 `.gs` 파일 4개는 각 구글 시트에 붙어 있는 Apps Script 코드입니다.
사이트 코드(index.html, ms_inbound.js, recipe.js, price.js)와 **함께** 바꿔야 합니다.

| 파일 | 붙여넣을 구글 시트 |
|---|---|
| `1_raw_orders.gs` | 원재료 발주 DB 시트 |
| `2_ms_inbound.gs` | 엠즈 입고 DB 시트 |
| `3_recipe.gs` | 레시피 DB 시트 |
| `4_product_price.gs` | 제품단가 DB 시트 |

## 배포 순서 (반드시 이 순서로)

### 1. 사이트 코드 먼저 반영 (GitHub)
- 사이트 코드가 먼저 바뀌면, GAS가 아직 옛 버전인 동안에는 각 탭이 **"저장 중지 (GAS 업데이트 필요)"** 로 표시되고 저장을 하지 않습니다. 불러오기는 정상입니다.
- 반대로 GAS를 먼저 바꾸면, 옛 사이트 코드는 저장이 거부돼도 "저장됨"으로 표시하므로 **사이트 먼저** 반영합니다.

### 2. GAS 4개 교체 (시트마다 반복)
1. 해당 구글 시트 → **확장 프로그램 → Apps Script**
2. 기존 코드를 **전부 지우고** 해당 `.gs` 파일 내용을 붙여넣기 → 저장(Ctrl+S)
3. 오른쪽 위 **배포 → 배포 관리**
4. 기존 배포 옆 **연필(수정)** 아이콘 → **버전: 새 버전** 선택 → **배포**
   - ⚠️ **"새 배포"를 누르면 웹앱 주소가 바뀝니다.** 꼭 "배포 관리 → 수정 → 새 버전"으로 하세요.
5. 권한 승인 창이 뜨면 본인 계정으로 허용

### 3. 확인
1. 모든 기기(PC·모바일)에서 사이트를 **새로고침**합니다. 예전에 열어 둔 탭은 닫습니다.
2. 4개 탭(원재료·엠즈 입고·레시피·제품단가) 상단 상태가 **"DB 연동됨"** 인지 확인합니다.
3. 각 탭에서 **[DB 저장]** 을 한 번씩 누릅니다 → "저장되었습니다" 확인.
   - 이때 엠즈 시트에 `MS_DB`, 제품단가 시트에 `PRICE_DB`, 레시피 시트에 `레시피이미지` 탭이 새로 생깁니다.
   - 레시피 시트의 첫 번째 탭 이름은 `레시피DB`로 바뀝니다.
4. 사이트를 한 번 더 새로고침해 데이터가 그대로인지 확인합니다.

## 바뀐 점 요약
- **저장 결과 확인**: 서버가 실패하면 화면에도 "실패"로 표시합니다. (기존: 실패해도 "저장 완료")
- **불러오기 실패 시 저장 중지**: 이 기기에 남은 옛 사본으로 DB를 덮어쓰지 않습니다.
- **리비전(충돌 방지)**: 다른 기기가 먼저 저장했으면 저장을 거부하고 새로고침을 안내합니다.
- **먼저 지우지 않음**: 검증 → 한 번에 덮어쓰기 → 남는 행만 정리. 셀 한도(5만자) 초과 시 시트를 건드리지 않고 거부합니다.
- **셀 한도 해결**: 엠즈·제품단가는 4만자씩 나눠 여러 행에 저장, 레시피 사진은 별도 시트, 원재료 월말 스냅샷도 4만자씩 분할.
- **텍스트 보존**: 규격 `1/2`, 품목코드 `01234` 등이 날짜·숫자로 바뀌지 않음. 날짜는 Asia/Seoul 고정.
- **위험 기능 제거**: 원재료 `clearAll`, 레시피 "주소만 열어도 저장", 레시피 JSONP.
- **샘플 데이터 자동 삽입 제거**: 엠즈 10~11월 고정 데이터, 레시피 '표준 식빵', 레시피 [샘플추가] 버튼, 제품단가 빈 DB 자동 저장.
- **레시피 자동 저장**: 수정 1.5초 뒤 자동 저장. 저장 전 창을 닫으면 경고. 다음 접속 시 미저장 수정분 복구(그 사이 DB가 바뀌었으면 브라우저에 백업).
- **엠즈 재업로드**: 같은 날짜를 다시 올려도 기사·운임·메모·상태(·직접 고친 제목) 유지. 운임 0원 입력 시 250,000원으로 바뀌던 오류 수정.

## 2026-11-20 새 배포 주소 적용 (v2.6.1)
- GAS 4종을 "새 배포"로 올려 웹앱 주소가 바뀌었으므로 사이트 기본 주소를 새 주소로 교체했습니다.
- 각 기기 브라우저에 저장돼 있던 예전 주소는 사이트 첫 접속 때 한 번 자동으로 지워져 새 주소를 사용합니다.
- **예전 배포(옛 주소)는 옛 코드로 계속 동작합니다.** 확인이 끝나면 각 Apps Script의 배포 관리에서 예전 배포를 **보관처리**하세요.
